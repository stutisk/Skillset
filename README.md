# Framer Frontend Assignment

A responsive frontend implementation built in Framer using React/TypeScript code components and live API data.

## Live Demo

[View the live Framer project]((https://blushing-sparrow-309073.framer.app/))

## Repository

This repository contains the code used for the assignment, including the custom Framer code components and API integration.

## Features

- Responsive UI
- Live API data integration
- Loading states with skeleton UI
- Error handling with retry functionality
- Empty states
- Conditional "Refundable" badge
- Reusable React/TypeScript components
- Responsive behavior across screen sizes

## Tech Stack

- Framer
- React
- TypeScript
- JavaScript
- REST API

## Getting Started

The project was developed for Framer and the primary implementation is available through the code files in this repository.

## Notes

The UI is designed to handle different API states, including loading, successful responses, empty results, and failed requests.

Built as part of a frontend developer assignment.
